\begin{abstract}
Current Large Language Models (LLMs) rely on fragile external text wrappers to enforce security and privacy policies. Because continuous activations flow through unrestricted continuous spaces, external wrappers are vulnerable to prompt injections and activation probes. We introduce \textbf{Neural State Architecture (NSA)}, a computational paradigm that embeds typed activations $h = (m, \sigma_h, \sigma_s, \nu)$ and state transition operators $(w, V)$ directly into neural forward passes. NSA enforces information security policies via a mathematical product state lattice algebra, making unauthorized information flow mathematically impossible at the attention layer via rigorous Hard Policy Semantics, while introducing Risk-Weighted Soft Semantics for post-hoc retrofitting. We validate NSA across synthetic benchmarks, demonstrating $0.00\%$ prompt injection hijack rate when structural constraints are combined with value alignment.
\end{abstract}

\section{Introduction}
Modern Large Language Models (LLMs) process all contextual inputs within a single untyped vector space $\mathbb{R}^d$. This architecture fails to provide mathematical guarantees regarding information boundaries.

\begin{definition}[Typed Product Lattice]
Let $\Sigma$ be a product state space defined over multiple bounded join-semilattices (e.g., Security, Confidence, Provenance, License). Each token hidden state at layer $l$ is represented as a coupled quad-tuple:
\begin{equation}
h_i^{(l)} = \left( m_i^{(l)}, \sigma_{h,i}^{(l)}, \sigma_{s,i}^{(l)}, \nu_i^{(l)} \right)
\end{equation}
where $m_i$ represents the semantic activation, $\sigma_{h}$ represents the hard structural state (Confidentiality, Integrity), $\sigma_s$ represents the soft operational state (Confidence), and $\nu$ represents the value/preference layer.
\end{definition}

\section{Information-Flow Governance \& Typed Declassification}

State-aware attention calculates query-key compatibility by composing semantic similarity with state transition permission:
\begin{equation}
A_{ij} = \text{Softmax}\left( \frac{Q_i K_j^T}{\sqrt{d_k}} + M_{\text{state}}(\sigma_i, \sigma_j) \right)
\end{equation}

When token $j$ possesses a security clearance higher than token $i$, $M_{\text{state}}(\sigma_i, \sigma_j) \to -\infty$, reducing $A_{ij} \to 0$ (Hard Policy Semantics). For retrofitted unconstrained LLMs, applying a rigid mask causes severe out-of-distribution activation spikes, necessitating a Risk-Weighted Soft Policy mask.

\subsection{Typed Declassification Primitive}
Downward reclassification algebraically requires passing an explicit typed capability:
\begin{equation}
D: (\sigma, c_D) \to \sigma'
\end{equation}
where $\text{Valid}(c_D, \sigma, \sigma') = 1$ and $c_D = (\text{issuer}, \text{purpose}, \text{scope}, \text{expiry}, \text{max downgrade})$. This transforms declassification into a formal, auditable computational primitive rather than an unconstrained vulnerability.

\section{Formal Non-Interference Proof}

\begin{theorem}[Non-Interference Bounds]
Let $m_{\text{src}}$ be a secret semantic token activation with state $\sigma_{\text{src}} = \text{CONFIDENTIAL}$, and let $m_{\text{dst}}$ be a public output activation with state $\sigma_{\text{dst}} = \text{PUBLIC}$. Under hard state masking ($M_{\text{state}} = -\infty$), the mutual information satisfies:
\begin{equation}
I(m_{\text{src}}; m_{\text{dst}} \mid \sigma) = 0
\end{equation}
\end{theorem}

\begin{proof}
By definition of state-aware attention, when $s_{\text{src}} \not\le s_{\text{dst}}$, the attention weight $A_{\text{dst}, \text{src}} = 0$. Consequently, the value aggregation step yields:
\begin{equation}
v_{\text{out}} = \sum_{j \neq \text{src}} A_{\text{dst}, j} V(m_j)
\end{equation}
Because $v_{\text{out}}$ is functionally independent of $m_{\text{src}}$, the conditional probability $P(m_{\text{dst}} \mid m_{\text{src}}, \sigma) = P(m_{\text{dst}} \mid \sigma)$. Thus:
\begin{equation}
I(m_{\text{src}}; m_{\text{dst}} \mid \sigma) = H(m_{\text{dst}} \mid \sigma) - H(m_{\text{dst}} \mid m_{\text{src}}, \sigma) = 0
\end{equation}
\end{proof}

\section{Conclusion}
Neural State Architecture demonstrates that security and privacy policies do not require fragile external wrappers.
